# ⚡ 💊 NUTRO-SUPPLEMENT | Interactive Health & Supplement Dashboard 🚀 🏋️‍♂️

An interactive, responsive single-page web application designed for tracking supplement protocols, daily schedules, monthly dosage budgets, and health indicators! 📊 ✨ 🧘‍♂️

---

## 🌟 🚀 Features

- 📑 **Interactive Supplement Master Table:** Displays details, dosages, timing, benefits, priority rankings, and local pricing! 🏷️ 💡 💵
- ⏰ **Timing & Schedule Protocol:** Clean breakdown of optimal intake windows (Pre-workout 🏋️‍♂️, Breakfast 🥣, Dinner 🍽️, Bedtime 😴, etc.).
- 🧮 **30-Day Cost Calculator:** Real-time dynamic calculator to estimate monthly expenses based on custom product selections and dosage quantities! 💰 📊 ⚡
- ⚖️ **BMI Calculator:** Instant Body Mass Index calculator with health category feedback and actionable advice! 🎯 📈 🧘‍♀️
- 🌗 **Dark / Light Theme Toggle:** Custom theme switcher with state handling and gold aesthetic borders! 🌙 ☀️ ✨
- 🔍 **Detailed Modal View:** Interactive popup cards for in-depth supplement descriptions and safety guidelines! 📜 🚨 🛡️
- 📱 **Fully Mobile Responsive:** Optimized grid layouts and table views tailored for all screen sizes from mobile to desktop! 💻 📲 🖥️
- 🚀 **Smooth UX Animations:** Custom side-tab "Back to Top" rocket launch animation and micro-interactions! 🎉 💫 🎈

---

## 🛠️ 💻 Tech Stack & Technologies

- 🌐 **HTML5:** Semantic structural layout. 🧱
- 🎨 **Tailwind CSS:** Modern utility-first styling with custom theme extension. 🦄 ✨
- ⚡ **Vanilla JavaScript (ES6+):** Dynamic DOM manipulation, state management, and calculation logic. 🧠 🛠️
- 🔣 **FontAwesome:** Rich iconography. 🎭 🎯
- 🔤 **Google Fonts:** `Inter` & `Cairo` typography. 📝 🎨
